CodeFRAME™

A project delivery system for AI-written software.

CodeFRAME owns everything before and after the code: requirements, task planning, verification and release. The coding itself goes to the agent of your choice.

Limitations

CodeFRAME is in public beta (0.9.5). The Golden Path CLI (cf init/prd/tasks/work/proof/pr) and the v2 API are stable enough to build on. The web UI and anything marked in progress in the roadmap are still moving, and on-disk .codeframe/ formats may change between betas. Report rough edges.
